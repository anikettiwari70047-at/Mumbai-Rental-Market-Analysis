# Mumbai Rental Market Analysis

## Project Overview
This project analyzes the Mumbai rental housing market using Python and Power BI.

## Technologies Used
- Python
- Pandas
- Jupyter Notebook
- Power BI
- CSV Dataset

## Files
- `mumbai_rental.ipynb` – Python data analysis
- `mumbai_rentals.csv` – Dataset
- `Mumbai_Rental_Market_Analysis (1).pbix` – Power BI dashboard

## Objective
The objective of this project is to analyze Mumbai rental data and identify useful patterns and insights from the dataset.

## Analysis
The project includes data analysis and visualization of Mumbai rental market information using Python and Power BI.
