# 🏠 Mumbai Rental Market Analysis

> **Exploring Mumbai's Rental Housing Market through Python, Data Analysis & Power BI**

---

## 📌 About the Project

**Mumbai Rental Market Analysis** is a data analytics project designed to explore and understand rental housing patterns in Mumbai.

The project combines **Python-based data analysis** with an interactive **Power BI dashboard** to transform rental data into meaningful insights.

The analysis focuses on rental prices, property types, rental value per square foot, and the relationship between metro accessibility and monthly rent.

---

## 🎯 Project Goals

The main objectives of this project are to:

- 📊 Analyze Mumbai rental property data
- 🏠 Understand the distribution of different property types
- 💰 Study monthly rental prices
- 📐 Analyze average rent per square foot
- 🚇 Examine the relationship between metro accessibility and rent
- 🔎 Identify useful patterns within the rental dataset
- 📈 Present analytical results through an interactive Power BI dashboard
